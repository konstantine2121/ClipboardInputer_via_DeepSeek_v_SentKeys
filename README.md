# ClipboardInputer

Дает возможность эмулировать последовательный ввод клавиш из буфера обмена.

## Ограничения 

Подходит только для ввода символов латиницы.

## Важно

Нужно проследить чтобы перед вызовом программы была выбрана английская раскладка клавиатуры.
После вызова программы есть ровно одна секунда чтобы выбрать/выделить/установить фокус на окно в которое будет производится ввод.
Ввод данных прервать нельзя.
Во время ввода переводить фокус на другие окна и программы - нельзя.

## Предпологаемый режим использования

Для программы создать ярлык и отправить его на рабочий стол.
Зайти в свойства ярлыка и задать комбинацию клавиш в окне Быстрый вызов.
